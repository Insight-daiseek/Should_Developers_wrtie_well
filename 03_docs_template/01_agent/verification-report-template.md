# 테스트·검증 보고서

> 이 리포트는 변경 사항을 어떻게 확인했고 어떤 결과가 나왔는지 알린다.
> 통과와 실패를 먼저 쓴다. 실행하지 않은 검증은 미실행으로 적는다.
> 한 문장에는 한 가지 결과만 담는다.

## 1. 결과

- 상태: `[통과 / 일부 실패 / 검증 불가]`
- 요약: `[검증 결과를 1~3문장으로 작성]`

## 2. 검증 환경

- 환경: `[운영체제, 런타임, 브랜치, 테스트 데이터 등]`
- 대상: `[기능, 변경 사항, 파일]`

## 3. 실행 결과

| 항목 | 방법 또는 명령 | 기대 결과 | 실제 결과 | 상태 |
| --- | --- | --- | --- | --- |
| `[항목]` | `[명령 또는 방법]` | `[기대 결과]` | `[실제 결과]` | `[통과 / 실패 / 미실행]` |

## 4. 실패 및 미실행 항목

- `[항목]`: `[이유, 영향, 필요한 조치]`
