# 아웃라인 생성

> 아웃라인 생성 과정

1. 02_themes.md 에서 구성한 주제 재배열

- 의존성 존재 => 아는 정보 -> 새 정보 순서 배열
    - "무엇을 -> 왜 -> 어떻게" 순서 배열 / 어떤 기능? -> 왜 필요하지? -> 어떻게 사용? 순서

- 시간 순서대로
    - 사용자의 행동 흐름
    - 삭제 기능은 주의사항이 더 중요하므로 삭제 시 주의사항 -> 사용법 순서 배열

- 중요도 순서대로
    - "왜" 기준
    - 기능 명세서에선 개발 배경 & 목적 설명
- 필요한 순서대로
    - 주제 간 의존성, 순서가 없다면 중요도나 필요한 순서대로 배열

2. 선정한 주제의 분량에 따라 제목 / 소제목 / 패러그래프 선정
