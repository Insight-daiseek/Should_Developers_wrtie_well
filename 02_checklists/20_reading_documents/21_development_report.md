# 개발 보고서 체크리스트

적용 대상: 개발 활동의 배경, 수행 내용, 결과, 해석을 보고하는 문서.

- [ ] 보고의 대상, 기간, 목적, 배경을 명시하는가?
- [ ] 목표 또는 검증 기준을 결과와 구분해 제시하는가?
- [ ] 수행한 주요 작업, 방법, 소요 기간, 소요 비용을 필요한 범위에서 설명하는가?
- [ ] 결과를 사실, 수치, 관찰 내용으로 명확히 제시하는가?
- [ ] 결과의 해석과 결과 자체를 구분하는가?
- [ ] 수치에는 기간, 기준, 비교 대상 등 판단에 필요한 맥락이 있는가?
- [ ] 한계, 미해결 문제, 후속 작업 또는 의사결정 요청을 명시하는가?

## 예시 구조

```text
프로젝트 개발 보고서
├─ 요약
│  ├─ 보고 목적
│  ├─ 핵심 결과
│  └─ 요청 사항 또는 다음 행동
├─ 배경과 목표
├─ 수행 내용
│  ├─ 주요 작업
│  ├─ 작업 기간
│  └─ 사용한 자원 또는 비용
├─ 결과
│  ├─ 결과 수치와 기준
│  └─ 주요 산출물
├─ 결과 해석
├─ 한계와 미해결 문제
└─ 후속 작업
```
