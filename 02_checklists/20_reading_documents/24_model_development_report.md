# 모델 개발 업무 보고서 체크리스트

적용 대상: 모델 개발의 목표, 데이터, 개발 방법, 평가 결과, 한계와 다음 단계를 보고하는 문서.

이 체크리스트는 `21_development_report.md`를 적용한 뒤 추가로 사용한다.

## 1. 개발 목표와 범위

- [ ] 모델이 해결하려는 문제와 업무 목표를 설명하는가?
- [ ] 모델의 입력, 출력, 사용 대상, 적용 범위를 명시하는가?
- [ ] 모델이 해결하지 않는 범위와 현재 제약을 구분하는가?

## 2. 입력 데이터와 가공 전략

- [ ] 데이터의 출처, 수집 기간 또는 범위, 규모, 주요 입력 항목을 설명하는가?
- [ ] 데이터 제외 기준과 제외한 이유를 설명하는가?
- [ ] 결측값, 중복값, 이상값을 어떻게 처리했는가?
- [ ] 데이터 변환, 정규화, 인코딩 등 가공 단계의 목적과 선택 이유를 설명하는가?
- [ ] 학습·검증·평가 데이터를 어떤 기준으로 나눴는가?
- [ ] 평가 데이터가 실제 사용 환경을 충분히 반영하는지 검토했는가?

## 3. 특정 요소 대응 전략

특정 요소란 모델의 성능, 안전성, 공정성에 영향을 줄 수 있어 별도 검토가 필요한 데이터 집단, 입력 조건, 예외 사례, 사용자 환경 또는 업무 규칙이다.

- [ ] 데이터 불균형, 드문 사례, 특정 조건의 성능 저하 여부를 확인했는가?
- [ ] 별도 대응이 필요한 특정 요소를 명시했는가?
- [ ] 각 특정 요소에 적용한 대응 전략과 선택 이유를 설명하는가?
- [ ] 대응 후 전체 성능과 특정 요소별 성능의 변화를 확인했는가?
- [ ] 개인정보, 민감 정보, 안전 문제와 관련된 처리 기준을 필요한 범위에서 설명하는가?

## 4. 모델 설계와 평가

- [ ] 모델 또는 방법을 선택한 이유를 설명하는가?
- [ ] 주요 설정, 학습 조건, 사용한 도구 또는 버전을 재현 가능한 수준으로 기록했는가?
- [ ] 비교 기준 모델 또는 이전 방법과의 차이를 설명하는가?
- [ ] 평가 지표의 의미와 선택 이유를 설명하는가?
- [ ] 전체 결과와 주요 조건·집단별 결과를 구분해 제시하는가?
- [ ] 실패 사례, 예상과 다른 결과, 현재 방법의 한계를 설명하는가?

## 5. 예시 구조

```text
모델 개발 업무 보고서
├─ 요약
│  ├─ 개발 목표
│  ├─ 핵심 결과
│  └─ 다음 요청 또는 결정
├─ 문제와 적용 범위
├─ 입력 데이터
│  ├─ 출처와 범위
│  ├─ 주요 입력 항목
│  └─ 제외 기준
├─ 데이터 가공 전략
│  ├─ 품질 문제 처리
│  ├─ 데이터 변환
│  └─ 학습·검증·평가 데이터 분리
├─ 특정 요소 대응 전략
│  ├─ 불균형 또는 드문 사례
│  ├─ 조건·환경별 대응
│  └─ 개인정보·안전 검토
├─ 모델 설계와 학습
│  ├─ 모델 선택 이유
│  ├─ 주요 설정과 학습 조건
│  └─ 비교 기준
├─ 평가 결과
│  ├─ 평가 지표와 기준
│  ├─ 전체 결과
│  └─ 특정 요소별 결과와 실패 사례
├─ 한계와 위험
└─ 다음 단계
```
