# 읽기형 문서 기본 체크리스트

읽기형 문서는 독자가 처음부터 끝까지 읽으며 내용의 논리와 핵심 메시지를 이해하는 문서다.

- [ ] 도입부에 문서의 주제, 목적, 전개 방식을 제시하는가?
- [ ] 소제목만 읽어도 배경, 핵심 내용, 결론 또는 다음 행동으로 이어지는 흐름이 보이는가?
- [ ] 독자의 판단에 필요한 핵심 주장·결론·주요 결과를 지나치게 뒤에 배치하지 않았는가?
- [ ] 각 문단의 첫 문장이 해당 문단의 핵심 주장 또는 요점을 전달하는가?
- [ ] 주장과 근거, 사실과 해석, 결과와 다음 행동을 구분하는가?
- [ ] 문서의 결론이 도입부의 목적과 연결되는가?
