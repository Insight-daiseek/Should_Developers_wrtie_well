# 기술 블로그 체크리스트

적용 대상: 기술적 문제, 해결 과정, 배운 점을 독자와 공유하는 문서.

- [ ] 대상 독자와 필요한 사전 지식을 도입부에서 안내하는가?
- [ ] 다루는 문제 또는 질문을 구체적으로 정의하는가?
- [ ] 문제의 맥락, 제약, 재현 조건을 필요한 수준으로 설명하는가?
- [ ] 해결 방법과 선택 이유를 구분해 설명하는가?
- [ ] 코드, 설정, 실험 결과 등 근거가 주장을 뒷받침하는가?
- [ ] 결과와 한계, 적용하기 적합하지 않은 조건을 함께 설명하는가?
- [ ] 독자가 배운 내용을 재현하거나 자신의 상황에 적용하는 데 필요한 정보를 제공하는가?

## 예시 구조

```text
기술 문제를 해결한 방법
├─ 요약
│  ├─ 다루는 문제
│  └─ 핵심 해결 방법
├─ 대상 독자와 사전 지식
├─ 문제와 맥락
│  ├─ 발생 조건
│  └─ 제약 사항
├─ 해결 과정
│  ├─ 검토한 방법
│  ├─ 선택한 방법과 이유
│  └─ 코드 또는 설정 예시
├─ 결과와 근거
├─ 한계와 적용 시 주의 사항
└─ 마무리
```
