# 외부 기능 명세서 체크리스트

적용 대상: 외부 사용자 또는 연동 개발자가 기능·인터페이스를 사용하도록 설명하는 문서.

- [ ] 기능의 목적, 사용 주체, 적용 범위를 설명하는가?
- [ ] 기능 또는 엔드포인트별로 입력, 출력, 오류를 같은 순서로 설명하는가?
- [ ] 입력값의 이름, 형식, 필수 여부, 조건, 허용 범위를 명시하는가?
- [ ] 출력값의 구조, 의미, 상태별 차이를 설명하는가?
- [ ] 오류의 조건, 코드 또는 식별자, 사용자의 대응 방법을 구분하는가?
- [ ] 인증, 권한, 호출 제한, 호환성 등 공통 제약을 기능별 설명과 분리하는가?
- [ ] 화면 또는 API 계약에 변경 조건과 호환성 영향이 있다면 명시하는가?

## 예시 구조

```text
외부 기능 명세서
├─ 개요
│  ├─ 기능의 목적과 범위
│  └─ 대상 사용자 또는 연동 대상
├─ 시작하기
│  ├─ 인증과 권한
│  └─ 공통 요청 규칙
├─ 기능 또는 API 목록
│  └─ 기능 A
│     ├─ 목적
│     ├─ 요청: 입력값과 조건
│     ├─ 응답: 출력값과 상태
│     └─ 오류: 조건과 대응 방법
├─ 공통 제약
│  ├─ 호출 제한
│  └─ 호환성
└─ 변경 사항
```
