# 프로덕트 매뉴얼 체크리스트

적용 대상: 제품 전체의 개념, 기능 지도, 역할별 사용 방법을 설명하는 문서.

- [ ] 제품의 목적, 대상 사용자, 지원 범위를 도입부에서 설명하는가?
- [ ] 제품의 주요 기능을 사용자가 이해할 수 있는 기능 지도 또는 목차로 제공하는가?
- [ ] 기능을 사용 목적 또는 제품 구성 요소 기준으로 일관되게 분류하는가?
- [ ] 역할·권한·플랜에 따라 가능한 기능이 다르면 차이를 명시하는가?
- [ ] 기능 간 이동, 연관 기능, 공통 설정의 위치를 안내하는가?
- [ ] 사용자가 제품 전체를 이해하는 내용과 특정 기능을 수행하는 내용을 구분하는가?
- [ ] 제품 전체에 적용되는 제약, 보안, 지원 환경을 별도 항목으로 정리하는가?

## 예시 구조

```text
제품명 사용자 안내서
├─ 제품 소개
│  ├─ 제품의 목적
│  ├─ 대상 사용자
│  └─ 지원 환경과 제한 사항
├─ 시작하기
│  ├─ 계정 만들기 또는 로그인
│  ├─ 초기 설정
│  └─ 화면 구성
├─ 주요 기능
│  ├─ 기능 A
│  ├─ 기능 B
│  └─ 기능 C
├─ 역할과 권한
├─ 자주 묻는 질문과 오류 대응
└─ 지원 및 문의
```
