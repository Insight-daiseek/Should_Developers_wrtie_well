# 사전형 문서 기본 체크리스트

사전형 문서는 독자가 필요한 정보를 찾아 읽는 문서다. 검증의 핵심은 정보 탐색성이다.

- [ ] 목차만 읽어도 문서의 범위와 주요 구성 요소를 예측할 수 있는가?
- [ ] 소제목에 독자가 검색하거나 찾을 단어가 직접 포함되는가?
- [ ] 기능, 절차, 제약, 오류 대응의 위치를 소제목만으로 찾을 수 있는가?
- [ ] 같은 수준의 항목이 기능별, 화면별, 사용 단계별 등 하나의 분류 기준을 따르는가?
- [ ] 핵심 정보가 여러 위치에 흩어져 있지 않은가?
- [ ] 한 항목을 이해하기 위해 다른 항목을 반드시 읽어야 한다면, 참조 관계나 선행 조건을 명시했는가?
- [ ] 공통 정보와 기능별 정보를 구분했는가?
