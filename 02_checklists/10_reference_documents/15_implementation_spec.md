# 기능 구현 명세서 체크리스트

적용 대상: 개발자와 QA가 기능을 구현하고 검증하도록 돕는 내부 문서.

- [ ] 기능 요구사항과 비기능 요구사항을 구분하는가?
- [ ] 기능의 시작 조건, 처리 흐름, 상태 변화, 종료 조건을 설명하는가?
- [ ] 데이터 모델, 입력·출력, 저장·조회 규칙을 필요한 수준으로 정의하는가?
- [ ] 외부 시스템, 내부 모듈, 비동기 작업 등 의존성을 명시하는가?
- [ ] 실패·예외 처리, 재시도, 복구 또는 보상 동작을 정의하는가?
- [ ] 성능, 보안, 권한, 관측성 등 비기능 요구사항을 구분해 설명하는가?
- [ ] 구현 완료와 QA 검증에 사용할 수 있는 수용 기준 또는 테스트 기준을 제공하는가?

## 예시 구조

```text
기능 A 구현 명세서
├─ 목적과 범위
├─ 요구사항
│  ├─ 기능 요구사항
│  └─ 비기능 요구사항
├─ 처리 설계
│  ├─ 시작 조건과 종료 조건
│  ├─ 처리 흐름
│  └─ 상태 변화
├─ 데이터와 인터페이스
│  ├─ 데이터 모델
│  ├─ 입력과 출력
│  └─ 외부·내부 의존성
├─ 예외와 복구
├─ 보안·성능·관측성
└─ 수용 기준과 테스트 기준
```
