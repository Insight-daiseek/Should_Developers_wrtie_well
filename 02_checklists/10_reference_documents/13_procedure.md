# 절차서 체크리스트

적용 대상: 정해진 작업을 동일한 방식으로 수행하도록 안내하는 문서.

- [ ] 절차의 목적, 적용 범위, 수행 주체를 명시하는가?
- [ ] 절차 시작 전 조건, 필요한 도구, 권한, 입력물을 제시하는가?
- [ ] 단계가 실제 작업 순서대로 배열되어 있는가?
- [ ] 각 단계의 담당자, 수행 행동, 완료 조건을 구분하는가?
- [ ] 단계 실패, 중단, 예외 상황의 대응과 재개 방법을 제공하는가?
- [ ] 되돌릴 수 없는 작업의 영향과 승인 조건을 먼저 알리는가?
- [ ] 절차의 최종 완료 기준과 산출물을 명시하는가?

## 예시 구조

```text
작업 A 절차서
├─ 목적과 적용 범위
├─ 수행 주체와 역할
├─ 시작 전 확인 사항
│  ├─ 필요한 권한과 도구
│  └─ 입력물과 사전 조건
├─ 작업 절차
│  ├─ 1단계: 준비
│  ├─ 2단계: 실행
│  └─ 3단계: 결과 확인
├─ 예외와 중단 대응
├─ 복구 또는 되돌리기
└─ 완료 기준과 산출물
```
