# 기능 매뉴얼 체크리스트

적용 대상: 사용자가 하나의 기능을 실행하고 오류에 대응하도록 돕는 문서.

- [ ] 기능의 목적과 사용 가능한 대상·권한을 설명하는가?
- [ ] 기능을 사용하기 전 필요한 계정, 권한, 설정, 입력값을 제시하는가?
- [ ] 사용 단계가 실제 화면 또는 조작 순서대로 배열되어 있는가?
- [ ] 각 단계에서 사용자가 수행할 행동과 기대 결과를 구분해 설명하는가?
- [ ] 주의사항, 제약, 되돌릴 수 없는 작업을 사용 단계보다 먼저 또는 해당 단계에 표시하는가?
- [ ] 자주 발생하는 오류와 사용자의 대응 방법을 찾기 쉬운 위치에 두는가?
- [ ] 기능을 성공적으로 완료했는지 확인하는 방법을 제공하는가?

## 예시 구조

```text
기능 A 사용 방법
├─ 기능 개요
│  ├─ 기능의 목적
│  └─ 사용할 수 있는 사용자
├─ 사용 전 확인 사항
│  ├─ 필요한 권한
│  └─ 필요한 설정 또는 입력값
├─ 사용 방법
│  ├─ 1단계: 기능 열기
│  ├─ 2단계: 정보 입력
│  └─ 3단계: 실행과 결과 확인
├─ 주의 사항과 제한
├─ 오류 대응
└─ 관련 기능
```
