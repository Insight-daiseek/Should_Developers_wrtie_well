# 공통 품질 체크리스트

- [ ] 독자가 필요한 정보를 정확하게 얻을 수 있는가?
  - [ ] 대상, 조건, 행동, 결과가 명확한가?
  - [ ] 서로 모순되거나 여러 방식으로 해석될 표현이 없는가?
- [ ] 독자가 적은 노력으로 정보를 찾고 이해할 수 있는가?
  - [ ] 제목, 소제목, 문단의 첫 문장이 핵심을 먼저 전달하는가?
  - [ ] 중복 설명과 독자의 목적에 무관한 정보가 없는가?
  - [ ] 정보의 순서가 이해 흐름을 방해하지 않는가?
- [ ] 문서의 어조가 긍정적이고 직접적인가?
  - [ ] 금지·제약을 설명해야 하는 경우를 제외하고 부정형을 불필요하게 사용하지 않는가?
- [ ] 원문의 사실, 수치, 정책, 기술적 의미를 추정해 변경하지 않았는가?
- [ ] 근거가 부족하거나 모호한 내용은 `확인 필요`로 표시했는가?
