# 독자와 주제 체크리스트

- [ ] 주 독자를 직무, 역할, 지식 수준으로 특정했는가?
- [ ] 독자의 목표를 문서를 읽은 뒤 수행할 행동으로 정의했는가?
- [ ] 독자의 프로덕트 지식, 기술 지식, 도메인 지식 수준을 고려했는가?
- [ ] 독자별 목적이나 필요 정보가 크게 다르면 문서를 분리해야 하는가?
- [ ] 문서의 범위와 범위 밖의 내용을 구분했는가?
- [ ] 주제를 Why, What, How로 검토했는가?
  - [ ] Why: 왜 필요한가? 배경·문제·목적은 무엇인가?
  - [ ] What: 무엇을 제공하거나 달성하는가? 범위·기능·결과는 무엇인가?
  - [ ] How: 어떻게 사용·구현·실행하는가? 절차·수단·주의사항은 무엇인가?
- [ ] 분량이 많거나 중요한 내용은 소제목으로, 짧은 내용은 문단으로 배치했는가?
